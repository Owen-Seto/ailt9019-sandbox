# Assessment Tasks

Purpose: Output a table of assessment methods and their weighting when the user inputs the location of the course description file.
When: A user inputs the location of the course description file.

Steps:
1. Read the course description file and extract the assessment methods and their weighting.
2. Type out the course name and course code first.
3. Output a table of assessment methods and their weighting.
